Implementation

โค้ดที่ Partner ต้องเขียน

ลำดับการเชื่อมต่อ: config → record/upload → Partner attach → playback

const config = { apiBaseUrl, publicKey }
const recorder = createRecorder(config)
const capture = await recorder.capture()
capture.start()

const clip = await capture.stop()
const { videoId } = await recorder.upload(clip, {
  orderRef,
  externalUserRef,
  merchantId,
}).promise

await partnerApi.saveVideoId(orderRef, videoId)

const { url } = await createPlayer({ apiBaseUrl, publicKey })
  .resolvePlaybackUrl(videoId)
video.src = url

The SDK is treated as a black box. Store the returned videoId with your document.
